# StellarTCG Set Catalog

Public, versioned set metadata for StellarTCG's optional administrator importer. Catalogs contain source data, coverage reports and artwork links; they do not contain the artwork library.

The builder scans physical Pokémon TCG sets in TCGdex's multilingual database. Missing scans, special printings and unimplemented battle rules are reported explicitly. Product contents and alternate packaging/card artwork require verified catalog entries; official pull odds are never invented.

The mod ships without any collecting content. Administrators explicitly select which sets to install. Existing sets and custom edits are preserved.

The initial catalog and reproducible builder are being published in this repository. Coverage totals are recorded in `catalog/coverage.json`.
